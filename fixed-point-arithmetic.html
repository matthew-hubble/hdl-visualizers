Automatic precision. The result format follows the usual bit-growth rules, so the answer is exact for +, − and ×:
A + B, A − Bn = max(nA, nB)m = max(mA, mB) + 1
A × Bn = nA + nBm = mA + mB (+1 if both signed)
A ÷ Bn = nA + mBm = mA + nB
Division is the exception: a quotient is rarely exact in any finite word, so the leftover is reported as a remainder in its own smallest exact format. Subtraction always produces a signed result; otherwise the result is signed if either operand is.
TI convention. Qm.n is m integer bits and n fraction bits, plus a sign bit when signed — m+n+1 bits wide, or m+n unsigned. Words are capped at 64 bits; if a growth format would exceed that, the page falls back and says so.
